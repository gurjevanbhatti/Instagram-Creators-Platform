# Instagram Engagement Analysis

## Overview
This project analyzes my Instagram post data to identify patterns in engagement (likes, comments, shares, saves) based on features like caption length, hashtags, post timing, and reel type. It uses statistical tests, clustering, and classification models to explore what factors drive higher engagement.

## Files
- **EDA_cleandata.py** — Exploratory Data Analysis on cleaned post data  
- **analyze_cleandata.py** — Statistical tests and modeling (logistic regression, random forest, PCA, clustering)  
- **make_post_cleandata.py** — Processes raw Instagram JSON/CSV into a cleaned dataset for analysis  
- **make_followers_cleandata.py** — Processes audience data into a cleaned format for future analysis  
- **CMPT 353 Project Report.pdf** — Final written report with results and discussion
